# Learn Obsidian with Phoebe

**Obsidian & Linked Notes** - six 45-minute sessions on building a research vault whose notes
know their neighbours: local Markdown files, wikilinks and backlinks, atomic notes and Niklas
Luhmann's slip box (what it was, and the argument over how much it explains), maps of content,
what the graph view does and does not tell you, and renaming and growing a vault safely.

The running case, Ines, is a constructed freelance user researcher. Session 4 is the **link
bench**: breadth-first search, degree and connected components run in the browser on her
constructed 192-note vault, comparing folders, tags, idea links and maps of content on twelve
"find everything about X" questions, with an anti-lever (link every mention of every term) and a
break (rename 20 notes outside Obsidian).

- `index.html` - landing page and knowledge map
- `courses/01-...06-` - the sessions (4 is the bench)
- `assets/ob-sample.js` - the constructed vault (generated by `materials/build_ob_vault.py`)
- `assets/ob-live.js` - the bench engine; `materials/ob_reference.py` reproduces every number

Static HTML, no build step. Obsidian features were read from the official help in October 2026;
features change, so check the current help before relying on a menu name.

By Phoebe Fu.
