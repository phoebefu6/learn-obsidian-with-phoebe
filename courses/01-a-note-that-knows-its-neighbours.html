Part 1 · covers what a vault is, on disk

A folder of files you already own

5 min live

Obsidian's help puts it plainly: it stores your notes as Markdown-formatted plain text files in a vault, and a vault is a folder on your local file system, including any subfolders. Everything clever Obsidian does sits on top of those files. Take the app away and the notes are still there, readable in any text editor.

LiveLocal-first means the files come first3 min▶

Because notes are plain text files, the help notes that you can use other text editors and file managers on them, and Obsidian refreshes the vault to keep up with changes made outside it. You can open several folders as separate vaults, for example one for work and one for study. Inside each vault Obsidian creates a .obsidian folder for that vault's settings; most systems hide folders that start with a dot, so you may not see it in Finder until you show hidden files.

Two practical rules come straight from the help. Do not put a vault inside another vault, because links are local to a vault and may not update correctly. And do not create a vault inside Obsidian's own system settings folder. Anywhere else your operating system allows is fine, including a folder you already sync with iCloud, Dropbox, OneDrive or Git.

Self-studyThe metadata cache, and when to rebuild it2 min▶

To stay fast, Obsidian keeps a local record of metadata about the files in your vault, which the help calls the metadata cache. It powers many features, from the graph view to the outline. It is rebuilt from the files, never the other way round, so it can be thrown away safely. If it ever drifts out of sync with the files (rare, usually after heavy edits outside the app), rebuild it under Settings, Files and links.

This is the quiet reason backlinks work. A link is written in exactly one file, the one that contains [[...]]. The note being linked to is never edited. Obsidian reads every file, notices the link, and shows it from the other side. Part 2 makes that visible.

Real world

The export that lost the links. A familiar pattern: a researcher keeps years of notes in an app that stores them in its own database, then the team switches tools and the export arrives as a heap of files with every internal link turned into dead text. Notes that live as plain Markdown files in a folder never need exporting; the folder is the export.

Part 2 · covers wikilinks and backlinks

Write one link, get two directions

5 min live

Type two square brackets, pick a note, and you have written a wikilink: [[Drop-off clusters at the first form that asks for an ID number]]. That link lives only in the note you typed it in. Open the other note and its backlinks panel already lists the first one, under Linked mentions. Nobody wrote that backlink; Obsidian worked it out.

LiveWikilinks, and the Markdown alternative3 min▶

Obsidian supports two link formats that mean the same thing: the wikilink [[Three laws of motion]] and the standard Markdown link [Three laws of motion](Three%20laws%20of%20motion.md). Wikilinks are the default because they are compact. If other tools must read your notes, switch off Use [[Wikilinks]] under Settings, Files and links; typing [[ still autocompletes and Obsidian writes the Markdown form for you.

A link to a note that does not exist yet is allowed. Click it and Obsidian creates the note. That makes linking a way of planning: write the idea's name now, fill it in later. The help warns that the characters # | ^ : %% [[ ]] may not work inside a link, so keep them out of note titles.

LiveReading the backlinks panel2 min▶

The Backlinks core plugin shows two collapsible sections for the active note. Linked mentions are notes that contain an internal link to it. Unlinked mentions are places where the note's name appears without a link (Part 3). Options let you show more context around each mention, change the sort order and filter the list. If the tab is missing, run Backlinks: Show backlinks from the command palette; turn on Backlink in document to show them at the foot of every note instead.

The working habit: before you add to a note, read its backlinks. They are every earlier moment you thought this idea was relevant to something else, which is often more useful than the note itself.

Self-studyOutgoing links: the same idea, facing out2 min▶

The Outgoing links core plugin is the mirror image. Its Links section lists every link in the active note; its Unlinked mentions section lists text in the active note that matches the name or alias of another note in the vault. Between the two panels you see a note's whole neighbourhood: who it points at, who points at it, and who it should probably point at.

Link the idea, not the word. A link says "these two thoughts belong together", so it carries the most when it sits inside a sentence that says why. "P18 gave up at the ID form, which is the pattern in [[Drop-off clusters at the first form that asks for an ID number]]" beats a bare list of links at the bottom.

Part 3 · covers unlinked mentions and aliases

The links you forgot to write

5 min live

Ines writes "notification fatigue" in a dozen interview notes long before she has a note with that name. When she finally creates it, Obsidian can find every place the phrase already appears. Those are unlinked mentions: the network that was there in the text, waiting for brackets.

LiveTurning a mention into a link3 min▶

Open the new note's backlinks and expand Unlinked mentions. Each row shows the sentence where the name appears. Linking it rewrites that sentence in the other note with brackets around the phrase, so the link is stored where the mention was, exactly like a link you typed. The Outgoing links panel offers the same move from the other side; there the help's instruction is to click the button with the note's name.

Not every mention deserves a link. "Notification fatigue" in a quote from P15 is the idea; "notification fatigue" in an email subject you pasted is not. Unlinked mentions is a list of candidates, and the judgement stays with you. Session 4 measures what happens when you link every mention without judgement.

Self-studyAliases: one note, several names2 min▶

People write the same idea several ways. Add an aliases property to the note, as a YAML list, and Obsidian treats each alias as another name: aliases appear in link suggestions, and Backlinks finds unlinked mentions of them too. Linking through an alias writes the link as [[Notification fatigue|alert overload]], keeping the real note name as the destination.

Front matter on the note "Notification fatigue"--- aliases: - alert overload - too many notifications ---

Properties get their own Part in session 3. For now, one alias list is enough.

Real world

The pattern that was in the notes all along. A familiar moment in research work: three clients in, someone asks "have we seen this before?" and the honest answer is "probably, somewhere". Creating one note for the pattern and reading its unlinked mentions turns "somewhere" into a list with sentences, in under a minute, without anyone having planned the link in advance.

Build-along

Ines's first five notes, linked

★ 22 min · everyone builds

Create a vault, write five short notes, link them by idea, and watch the backlinks appear. Use Ines's notes from the boxes below, or swap in five notes from your own work: one record of something that happened, one idea, one thing you read, and two more of whatever you have.

Create the vault and find it on disk. In Obsidian choose Create new vault, name it, and pick a folder you can find again. Then open that folder in Finder or File Explorer. It is empty apart from the hidden settings folder: that is the whole storage format.

Check yourself

Three questions

Clear all three and session 1 gets stamped in your passport.

1 · Ines links her interview note to an insight note. Which file changes?

The link is text in the note that contains it. Backlinks are computed from the metadata cache, which Obsidian rebuilds from the files, so the linked note is never edited. There is no separate database of links to lose.

2 · What does the Unlinked mentions section of a note's backlinks list?

An unlinked mention is the name sitting in the text with no brackets. Linking it writes the brackets in the note where the mention is. Notes with no links are orphans, a graph view filter covered in session 5.

3 · Why does the help advise against putting one vault inside another?

Links resolve within a vault. A vault nested in another sees the same files from two places, and link updates can go wrong. Separate vaults side by side are fine.
